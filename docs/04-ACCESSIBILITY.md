# 04 Accessibility

La cible du nouveau projet est : **WCAG 2.2 niveau AA**.

Principes minimum :

- HTML sémantique
- Navigable au clavier
- Focus visible
- Pas de `div` cliquable lorsqu'un `button` convient
- Labels de formulaires
- Erreurs compréhensibles
- RTL/bidi prévu dès l'architecture
- `prefers-reduced-motion`
- Zoom 200 % fonctionnel
- Contraste suffisant
- Textes alternatifs
- Pas d'emoji utilisé comme icône d'interface

L'intégration axe-core sera prévue pour les futures sessions.

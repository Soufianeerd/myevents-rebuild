# Accessibility Contract

Cible normative : **WCAG 2.2 AA**.

## Exigences

- Clavier intégral (Focus visible et non obscurci)
- Sémantique HTML correcte
- Contraste suffisant
- Target Size (Minimum 44x44 ou 24x24 selon contexte 2.2)
- Reduced motion (support media query)
- Screen reader (Aria-labels)
- Responsive
- RTL (lorsque pertinent)
- Pour le drag & drop dans le Studio : alternative clavier requise.
